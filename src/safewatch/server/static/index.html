왼쪽 알림 큐에서 사건을 선택하세요.

AI는 위험상황을 탐지·정리할 뿐이며, 최종 판단과 신고는 관제자가 합니다.
대응 시간 KPI — 사건 발생 → 관제자 이해 → 신고 준비까지

정의: 탐지 지연 = 상황 시작 추정 시각→사건 생성 · 알림 지연 = 상황 시작→관제자 알림 · 인지 시간 = 알림→관제자 최초 열람 · 상황 파악 = 열람→확인(ACK) · 신고 준비 = 확인→신고정보 확정 · 전체 대응 = 상황 시작→신고 완료 기록(없으면 확정). 운영자 정밀도 = 관제자 피드백 기준 정탐/(정탐+오탐).

시나리오 재생 (합성 CCTV)

모델·데이터 없이 전체 흐름을 시험하기 위한 가상 영상입니다. [정상]은 위험과 비슷한 정상 상황(오탐 시험용)입니다.

실제 영상 / IP 카메라 연결

녹화 파일 경로 또는 RTSP URL (예: rtsp://user:pass@192.168.0.10:554/Streaming/Channels/102). 실제 인식 백엔드(YOLO pose + ByteTrack + COCO 객체)가 사용됩니다. 처음 실행 시 모델 가중치를 내려받습니다.
