# 02. Gap Analysis

## 1. 이미 해결된(상용화된) 기능 — 차별점으로 주장 금지

| 기능 | 선례 |
|---|---|
| 사람·차량 객체 탐지, 배회·침입·쓰러짐·싸움·방화 이벤트 탐지 | KISA 인증 제품 다수, 지자체 선별관제 |
| 선별관제(이벤트 발생 카메라만 관제화면에 표출) | 지자체 다수, 서초구 엣지형 |
| 총기/흉기 탐지 + 사람 검증 | ZeroEyes |
| 객체·행동·장소 맥락 결합 위협 판단 | **Ambient.ai Context Graph** |
| VLM 기반 맥락 인지·판단 근거 제시 | 서울시 2026 시범, Ambient.ai, 슈퍼브에이아이 |
| 영상 요약·자연어 검색·리포트 생성 | NVIDIA VSS, 슈퍼브에이아이, BriefCam |
| 인상착의 검색, 이벤트 상관 | Avigilon Appearance Search, Genetec Citigraf |
| 112 신고 시 주변 CCTV 영상·도주경로 제공 | 스마트시티 통합플랫폼 |
| 다중 위험신호 가중합 위험도 | 국내 특허 다수 (KR101513215B1 등) |

> **결론**: "객체+행동+시간+공간 종합"이라는 **개념 자체는 이미 선례가 있음**. 차별화는 개념이 아니라 **(a) 관계·시간 추론의 구체 구조, (b) 검증 방법, (c) 관제·신고 워크플로우의 측정 가능한 단축**에서 나와야 함.

## 2. 아직 해결이 어려운 문제

| 문제 | 근거 | 현실적 대응 |
|---|---|---|
| CCTV 거리·해상도에서 **흉기(칼) 탐지** | 소형객체 AP 낮음, 휴대폰·지갑 혼동 | 흉기 단독 판정 금지. "손에 든 길쭉한 물체" + 자세·상호작용을 증거로 누적 |
| **오탐** (관제 부담의 핵심) | 감사원 지적, 서울시 월 35만 건(개선 후에도) | 정상-유사 상황 hard negative 평가, 카메라-시간당 오탐(FP/cam-h)을 1차 지표로 |
| 희귀 사건 → **실제 데이터 부족**, 연출 데이터 도메인 갭 | AI-Hub 데이터 대부분 연출 | 연출 데이터 학습 + 실 CCTV 정상 영상으로 오탐 측정 분리 |
| **의도 예측** (공격 전 단계) | 학술적으로 미해결 | 범위 제외. "현재 진행 중인 상황"만 판단 |
| **비중첩 다중 카메라 재식별** | MTMC HOTA 2025 28.75% (3위) | 자동 추적 대신 "후보 제시 + 관제자 확인" 방식 |
| VLM **환각·시간 추론 약함**, 비용 | [S30][S31] | VLM은 상시 판정에 쓰지 않고, 상위 이벤트 검증·요약에만 사용. 출력은 트랙/자세 증거와 교차검증 |
| 야간·IR·우천·군중 밀집 | 일반적 한계 | 조건별 성능 분리 리포트, 성능 저하 조건에서 신뢰도 하향 |
| 성능 주장의 독립 검증 부재 | Evolv 사례, 대부분 업체 수치 비공개 | 공개 가능한 평가 프로토콜·리포트 자체를 산출물로 |
| 대응 시간 단축 효과의 **정량 근거 부족** | 공개된 사용자 연구 거의 확인 안 됨(추가 조사 필요) | 관제자 사용자 실험 설계 |

## 3. 차별화 가능한 부분 (후보 — 검증 전 가설)

| # | 차별화 가설 | 기존과 다른 점 | 검증 방법 |
|---|---|---|---|
| D1 | **사람 간 관계·시간 추론을 명시적 구조로 표현** (Interaction/Event Graph: 접근→회피→도주→추격→공격 같은 시퀀스 패턴) | Ambient 등은 비공개 블랙박스. 우리는 **증거 추적 가능한(explainable) 판단 근거** 제공 | 관계 특징 유무 ablation으로 event-level F1·FP/cam-h 비교 |
| D2 | **Hybrid 판정**: 경량 구조화 파이프라인 상시 실행 + VLM은 상위 후보에만 + **VLM 출력의 증거 정합성 검사** | Cerberus는 학술 캐스케이드, 서울시는 VLM 중심. 증거 교차검증으로 환각 억제 | VLM 단독 vs 구조화 단독 vs Hybrid 비교 |
| D3 | **정상-유사상황(hard negative) 중심 평가 셋** (장난 몸싸움, 조리용 칼 운반, 우산, 조깅 vs 도주) | KISA가 2025년에야 도입. 공개 벤치마크는 이상 위주 | 공개 평가 리포트 |
| D4 | **관제→신고 준비까지의 시간을 KPI로 측정**한 End-to-End 시스템 | 대부분 탐지 정확도만 제시 | 기존 VMS 화면 vs 우리 대시보드 A/B 사용자 실험 |
| D5 | **112 인계용 구조화 사건 패키지** (시간·위치·유형·위험물·인원·행동·방향·관련 CCTV·클립·근거) | VSS 등은 범용 요약. 국내 관제→경찰 인계 양식 특화 | 관제요원/경찰 인터뷰 후 양식 확정, 작성 시간 측정 |
| D6 | **임계값을 운영정책으로 분리** (PR 곡선에서 운영점 선택, 카메라·장소별 보정) | 고정 임계값 대신 검증 가능한 구조 | 장소별 calibration 전후 비교 |

> 주의: D1~D6도 특허·논문 정밀 조사(KIPRIS, Google Scholar) 전까지는 "차별화 가설"로만 표기. 특히 D1은 KR 특허들과 청구범위 비교 필요.
